# recursion-ascend.github.io

Personal homepage of Bowen Su. Plain HTML/CSS, no build step.

- `index.html` — all content
- `style.css` — styles (light/dark theme tokens at the top)
- `cv.pdf` — compiled CV, linked from the sidebar (add it yourself)
- `photo.jpg` — optional; see the comment above the avatar in `index.html`

Local preview:

```bash
python3 -m http.server 8000
```
